## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Personal presence preference to coordinator runtime | A social/profile choice must never cross into start/stop/restart lifecycle authority. |
| Personal identity UI to host administration | Profile controls are available to every identity, while coordinator badge mutation requires local-host authority. |
| Compact host drawer to workspace background | Host lifecycle actions remain modal, explicitly named, and isolated from background input. |
