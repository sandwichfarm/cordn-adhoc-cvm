## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| composer/session options → signed kind-9 envelope | Untrusted/editable presentation intent becomes authenticated recipient metadata. |
| signed envelope → MLS/persistence/decrypt | Recipient identity must survive without mutation or legacy/reaction breakage. |
| decrypted message → viewer-local DOM/layout | Invite capability and target metadata cross into visible/accessibility presentation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-01 | Tampering | protocol auth template and kind-9 tags | high | mitigate | Canonicalize once, include recipients in compact proof/finalized event, and fail mutation tests after signing. |
| T-24-02 | Information Disclosure | targeted invite projection | high | mitigate | Parse then filter before grouping and assert absence from DOM, accessibility, layout, errors, logs, and fixtures for non-target viewers. |
| T-24-03 | Spoofing | recipient identity | medium | mitigate | Accept only exact normalized 64-hex pubkeys from authenticated metadata; never resolve editable names. |
| T-24-04 | Tampering | reaction interoperability | medium | mitigate | Keep reaction p/e tags in their existing branch and test that ordinary recipient options cannot alter reaction semantics. |
| T-24-05 | Denial of Service | malformed recipient storage/input | low | accept | Defensive array/type/length validation reduces malformed input to legacy absence; bounded message tag arrays remain under existing message limits. |
