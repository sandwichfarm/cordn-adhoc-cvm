<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidebar/menu/dialog → room mutation | Untrusted UI timing and changing selection must not alter the frozen authorization target. |
| room target → coordinator control plane | Host deletion is privileged and must prove exact current-local coordinator ownership. |
| localStorage → navigation/parser | Malformed or foreign last-open state must not route or grant a deletion capability. |
| live session → local removal | In-flight persistence must not resurrect membership/cache after explicit leave/delete. |
| runtime errors → user diagnostics/tests | Private or internal room/coordinator material must not cross into visible errors or artifacts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-01 | Tampering / Elevation of privilege | `RoomTarget`, row callbacks, `deleteHostedRoom` | high | mitigate | Freeze both identity fields at menu open, re-load exact storage before mutation, and require active-local coordinator equality before host deletion. |
| T-16-02 | Tampering | `LastOpenRoomRecord`, storage migration | high | mitigate | Versioned scalar narrowing, exact reconciliation, verified write/read-back, and invalid/foreign reference removal. |
| T-16-03 | Denial of service / Tampering | active `ChatRoomSession`, removal event | high | mitigate | Discard the exact active session before deletion and synchronously reject later persistence from removed-session work. |
| T-16-04 | Information disclosure | dialog/recovery errors, debug log, tests | high | mitigate | Render generic room-named status only; exclude relay URLs, keys, invite tokens, messages, MLS state, and raw MCP/coordinator errors from UI and fixtures. |
| T-16-05 | Spoofing | reachability indicator | medium | mitigate | Green derives only from a confirmed exact room session; selection and transport-only readiness are separate facts. |
| T-16-SC | Tampering | package supply chain | low | accept | No package installation or upgrade is part of this plan. |
</threat_model>
