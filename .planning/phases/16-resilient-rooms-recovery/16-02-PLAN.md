<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| encrypted envelope → read ledger | Decrypted/authenticated delivery, duplicates, aliases, own echoes, and ordering determine whether state may increment. |
| localStorage → read-state parser | Malformed/oversized counters and cursors must not hide a room or poison UI arithmetic. |
| active view/document → acknowledgement | Selection/focus must not impersonate actual visible readable state. |
| composite room records → coordinator aggregate | Same room IDs under different coordinators must remain isolated. |
| unread event/live region → diagnostics | Activity metadata must not disclose message content or private membership material. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-06 | Tampering | `pullMessages`, `RoomReadState` | high | mitigate | Increment only beside authenticated append/dedup, baseline, remote-sender, and safe-integer gates; test duplicate/out-of-order/idempotent sync. |
| T-16-07 | Information disclosure / Tampering | `markRoomRead`, badge aggregation | high | mitigate | Key reads, writes, clearing, and sums by both coordinator pubkey and room ID; require exact active readable visible pane. |
| T-16-08 | Tampering / Denial of service | `readStoredRoom`, numeric aggregation | high | mitigate | Strict optional-field narrowing and safe-integer saturation; malformed read metadata is discarded without rejecting cached room data. |
| T-16-09 | Information disclosure | `ROOM_UNREAD_CHANGED_EVENT`, live region, tests | high | mitigate | Emit only composite IDs/counts and one room-title announcement; never include decrypted content, invite/MLS/key data, or raw transport errors. |
| T-16-10 | Spoofing | sidebar action/selection → acknowledgement | medium | mitigate | Menu and coordinator controls never call acknowledgement; visibility plus exact readable room are mandatory. |
| T-16-SC | Tampering | package supply chain | low | accept | No package installation or upgrade is part of this plan. |
</threat_model>
