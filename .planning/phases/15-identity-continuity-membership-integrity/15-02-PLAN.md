<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → identity/room parsers | Malformed, tampered, and mixed-version records enter reconciliation. |
| signer → stored `stablePubkey` | A signer attempts to claim immutable room membership authority. |
| live session → rotation transaction | Queued persistence/signing may survive local retirement. |
| composite selector → storage/UI mutation | Same room IDs at different coordinators must never collide. |
| secret-bearing runtime → diagnostics/artifacts | Legacy and durable private material must not be disclosed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-01 | Tampering | `readStoredRoom`, legacy secret decoding | high | mitigate | Parse/narrow every record, validate legacy secret encoding/length, and skip corrupt entries without granting authority. |
| T-15-02 | Spoofing / Elevation of privilege | `requireRoomSigner`, all attach paths | high | mitigate | Central derived-pubkey equality gate before session construction or send; mismatch remains cache-only. |
| T-15-03 | Elevation of privilege | `ChatRoomSession` queued persistence | high | mitigate | Retirement journal is consumed by Plan 15-03 only after matching sessions are retired; replacement remains unexposed until the transaction commits. |
| T-15-04 | Tampering | `roomIdentityKey`, migration, removal, Svelte keyed lists | high | mitigate | Carry both coordinator pubkey and room ID through every identity-sensitive read/write/delete/render and verify current target before alias deletion. |
| T-15-05 | Information disclosure | legacy `anonymousSecretKey`, cached state, tests | high | mitigate | Never log/snapshot secrets; validate only in memory; retirement scrubs authority-bearing fields while retaining decrypted display cache. |
| T-15-06 | Elevation of privilege | authenticated vs anonymous room creation | high | mitigate | Required signer parameter accepts the selected variant but anonymous persistence helpers are called only for `method === "anonymous"`; invariant tests cover isolation. |
| T-15-SC | Tampering | package supply chain | low | accept | No dependency installation or upgrade is part of this plan. |
</threat_model>
