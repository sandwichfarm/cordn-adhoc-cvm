<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| setup form -> encrypted key storage | A transient passphrase crosses from password controls into WebCrypto-backed KeyStorage and must reach no other persistence, logging, URL, publication, or evidence surface. |
| in-memory wizard draft -> ConfigStore/localStorage | Untrusted names, relay URLs, and choices must be fully validated before one durable completion boundary. |
| completed setup -> public profile/start lifecycle | Publication and startup are side effects allowed only after required key persistence and the complete config commit. |
| destructive reset -> browser persistence | Reset must remove encrypted identity and setup/preferences without leaving a bypass marker or stale autostart state. |
