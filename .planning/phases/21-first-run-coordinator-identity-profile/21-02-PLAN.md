<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted relay kind-0 -> metadata merge | Malformed, hostile, stale, or oversized content must not become executable/UI content or corrupt the outgoing profile. |
| coordinator KeyManager -> public signer | A copied coordinator secret crosses into nostr-tools only for one event and must be zeroized. |
| configured relays -> public network | Only shareable relay targets may receive the signed public event. |
| publication failure -> running coordinator/UI | Network causes must become a fixed retry state without lifecycle or information leakage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-06 | Spoofing | kind-0 signer | high | mitigate | Accept only CoordinatorStore KeyManager bytes, then assert signed pubkey equals coordinator identity and `verifyEvent` succeeds. |
| T-21-07 | Tampering | relay metadata merge | high | mitigate | Select newest event, parse a bounded non-array object defensively, preserve JSON-safe own fields, and overwrite only normalized name. |
| T-21-08 | Information Disclosure | errors/debug logs | high | mitigate | Convert all network/parse failures to fixed status/error codes and test that raw causes, URLs, event JSON, and secret sentinels never enter log/state. |
| T-21-09 | Denial of Service | multi-relay publication | medium | mitigate | Invoke every configured shareable target, serialize duplicate actions, accept one-or-more acknowledgements, bound profile queries, destroy the pool, and retain a retry path after total failure. |
| T-21-10 | Elevation of Privilege | operator/coordinator boundary | high | mitigate | The API has no operator signer input; tests use different operator/coordinator keys and require the coordinator pubkey. |
| T-21-11 | Repudiation | partial relay acceptance | low | accept | Product status records published after one acknowledgement without exposing infrastructure; exact per-relay audit history is outside the UI privacy contract. |
</threat_model>
