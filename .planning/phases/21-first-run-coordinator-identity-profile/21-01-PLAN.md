<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted browser config -> startup transaction | Untrusted/malformed localStorage must not grant setup completion or trigger coordinator side effects. |
| mutable settings -> static MCP transport constructor | Only a normalized persisted name may cross into public initialize metadata. |
| UI/autostart caller -> CoordinatorStore.start | Non-UI callers must face the same setup preflight as visible controls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-01 | Elevation of Privilege | CoordinatorStore.start | high | mitigate | Check explicit completion and normalized name before generation, lease, transport, status, and log side effects; assert zero calls in state-machine tests. |
| T-21-02 | Tampering | ConfigStore persisted migration | medium | mitigate | Parse the versioned record defensively, accept boolean completion only with a valid name, and perform one-time meaningful-name migration under tests. |
| T-21-03 | Spoofing | MCP/serverInfo name | medium | mitigate | Source both names from the same normalized immutable options snapshot and verify through a real initialize round trip. |
| T-21-04 | Information Disclosure | setup/start errors | medium | mitigate | Emit fixed user-safe validation text and keep raw localStorage values, keys, relay URLs, and stack traces out of logs and thrown UI messages. |
| T-21-05 | Denial of Service | legacy migration | low | accept | Invalid or default legacy data intentionally requires onboarding; it remains recoverable through the supported setup flow. |
</threat_model>
