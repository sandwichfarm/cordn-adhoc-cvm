<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| settings draft -> persisted/public coordinator identity | Invalid or duplicate input must not mutate configuration or publish. |
| browser app -> configured public relay | The signed event is public, but only the approved shareable target set may receive it. |
| relay acknowledgement/error -> user-visible status | Infrastructure detail must collapse into safe fixed states while retaining retry. |
| rename -> running transport | Public kind-0 updates immediately, while constructor-owned initialize metadata remains unchanged until explicit restart. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-18 | Tampering | settings name draft | medium | mitigate | Normalize on explicit save, reject empty, disable unchanged/busy actions, and test no write/publish for invalid input. |
| T-21-19 | Spoofing | browser-observed kind-0 | high | mitigate | Verify event signature/pubkey against the unchanged coordinator identity and assert the operator key differs. |
| T-21-20 | Information Disclosure | failure UI/console | high | mitigate | Render fixed copy only, capture browser console in tests, and prohibit raw URLs, causes, event JSON, full keys, bunker data, and stacks. |
| T-21-21 | Denial of Service | retry/duplicate activation | medium | mitigate | Serialize in-flight work, disable duplicate actions, keep coordinator lifecycle independent, and test one event attempt per activation. |
| T-21-22 | Repudiation | static vs public name timing | medium | mitigate | Show published status and a separate restart-required explanation; prove pre/post-restart initialize behavior. |
| T-21-23 | Elevation of Privilege | settings ownership | low | mitigate | Keep mutation only in local coordinator settings and do not add any personal/remote profile entry point. |
</threat_model>
