## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CoordinatorStore → presentation projector | Recovery phase, counts, room label, retry, exhaustion, and readiness cross from the verified state owner into decorative presentation. |
| Stored room display text → startup DOM | A persisted room name crosses into visible status/error copy and must remain escaped text rather than markup, selectors, or styles. |
| Decorative field → semantic controls | Pointer/focus/accessibility behavior crosses between a full-screen decorative layer and the progress/recovery controls above it. |
